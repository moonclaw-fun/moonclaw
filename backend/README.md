# 🧭 Command Guide

### 🗄️ Database Migrations

- **`yarn migration:generate`** → Generate migration file for **PostgreSQL**  
- **`yarn migration:up`** → Run the generated **PostgreSQL** migration  
- **`yarn migration:clickhouse`** → Execute **ClickHouse** migration script  

---

### ⚙️ Application Development

- **`yarn dev`** → Start **main NestJS app** in watch mode  
- **`yarn dev:worker`** → Start **worker NestJS app** in watch mode  

---

### 🧩 NestJS Resource Generator

- **`nest g resource hello-world`** → Generate new module **"hello-world"** with service + controller
